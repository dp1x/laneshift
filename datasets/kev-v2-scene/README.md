# kev-v2-scene training data

Generated by `python/build_kev_v2_scene.py` from the planned safe-teacher and
human recordings. Do not edit these files by hand.

- Prompt: scene, schema 2, L256 graph, rendered by the live `OnnxKevPolicy._encode` path
- Teacher: `safe_teacher`, every second accepted decision (~0.466 s sim)
- Human: 59 included rows from the preserved human session, train only
- Train: 16795 rows / 131 episodes / 131 seeds
- Validation: 4315 rows / 32 episodes / 32 seeds
- Test: 4317 rows / 32 episodes / 32 seeds
- Actions: {'BRAKE': 3484, 'LEFT': 378, 'RIGHT': 386, 'STAY': 21179}
- Unsafe human rows excluded: 1

The human and safe-teacher candidates are kept separately under `candidates/`.
Every row carries `split`, `label_source`, `scenario_seed`, `prompt_mode`,
`prompt_sha256`, `state_sha256`, `total_tokens`, and `label_quality` in its
provenance file. The test split is seed- and episode-disjoint and must remain
untouched until the final evaluation.

`--max_state 384` is a training state-token cap, not a 384-token model context.
Every row here is within the 256-token inference graph, and the original and
fine-tuned checkpoints must both be evaluated at L256.
