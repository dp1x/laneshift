## Limits

- The target is a deterministic rule, so a high score measures imitation, not driving skill.
- Rows inside an episode are 0.1 s apart; the effective sample size is far below the row count.
- No probabilities are recorded for rule-based labels, so calibration is of this MLP only.
- A human-labelled dataset and a held-out human session are still required before fine-tuning Kev.
