# Supervised baseline pilot

Generated by `python/train_baseline.py`. Labels are `rule_based` policy actions, not human decisions.

## Dataset

- rows: 1348, episodes: 15, endings {'crash': 8, 'timeout': 7}
- train: 764 rows, 9 episodes, seeds [11, 19, 23, 31, 37, 43, 47, 53, 67], actions {'LEFT': 15, 'STAY': 696, 'RIGHT': 12, 'BRAKE': 41}
- validation: 238 rows, 3 episodes, seeds [3, 41, 59], actions {'LEFT': 3, 'STAY': 201, 'RIGHT': 3, 'BRAKE': 31}
- test: 346 rows, 3 episodes, seeds [7, 29, 61], actions {'LEFT': 6, 'STAY': 295, 'RIGHT': 6, 'BRAKE': 39}

## Model

- MLP 33 -> 16 (tanh) -> 4 (softmax)
- learning rate 0.02, L2 0.001, batch 32, class weights balanced
- selected on validation log loss at epoch 44

## Limits

- The target is a deterministic rule, so a high score measures imitation, not driving skill.
- Rows inside an episode are 0.1 s apart; the effective sample size is far below the row count.
- No probabilities are recorded for rule-based labels, so calibration is of this MLP only.
- A human-labelled dataset and a held-out human session are still required before fine-tuning Kev.
